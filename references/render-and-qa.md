# 渲染与验证

## 确定性

暴露 `window.videoSpec` 和 `window.captureFrame(t)`，每次直接从绝对时间重建可变状态，不能靠累计 delta。同一时刻在 0→t、t2→t 两种跳转顺序下应返回相同像素；shader time、随机粒子、相机、可见性都要纳入重置。

文字切句使用半开区间 `[start,end)`。不要混合分属两句的时间采样；否则一个最终编码帧会同时出现两句。确实要运动模糊时，对连续几何单独采样，保留文字瞬时状态。

## 空间字与可读字幕

空间文字在动作完成时应有清晰、可读的停留；不能只依据其包围盒判断。辅助字幕可以作为屏幕层，保持字号与安全区。不要通过取消所有空间文字深度测试掩盖构图问题。接近镜头的物体应提前退场或调整路径，不能突然铺满画面遮字。

## 导出

Python renderer 只连接受信任的 localhost HTTP 服务。它不会启动服务或安装依赖。端口可配置，存在的输出文件不会被覆盖。FFmpeg 缺失、音频路径错误、JS 报错或音频时长不符时给出明确错误。测试用短片与完整歌曲导出分别记录。

## 最终文件检查

1. 对最终 MP4 运行 ffprobe 和整段解码，确认规格、时长、音视频流。
2. 在最终分辨率看每一类文字和场景；覆盖每句关键状态、句界前后、最大/最小字号、近镜物体与结尾。
3. 实际播放核对时序、节奏、闪烁、音轨和语义结果；截图不能证明动态通过。
4. 保留旧失败帧与新版对应时点；同类组件一起检查。需要独立审查时给审查者最终编码帧，不能只给源码和自评。
5. 报告明确区分机械检查、实际像素检查、听觉检查、语义判断与用户审美认可。

本包 smoke_check.py 只覆盖浏览器错误、关键帧非空和跳转一致性；不能替代上述整片检查。
