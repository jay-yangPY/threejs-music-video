# 音频与歌词时序

先用 `ffprobe` 读取音频真实时长与声道，保留原文件哈希。用波形/短片段试听确定起唱、空拍、间奏和尾奏；不要先凭歌词布局后强行对齐音频。

## 可选分析链

- Demucs：在人声难以识别或需要鼓点驱动时做分轨。按其官方文档安装；先检查已有模型缓存，说明下载和资源需求。不要为了工具清单齐全强制分轨。
- Whisper：生成粗转录和分段候选，优先人工提供的正确歌词；漏唱、重复副歌和英文品牌词都可能误识别。它给出的时间不是最终精确音节时点。
- CTC：在已经有正确歌词、语言模型相符、音频采样率正确时做辅助强制对齐。混唱、长音和零时长估计需要回退到句/短语级。模型接口与依赖可能变化，查对应官方文档后实施，不复用私有路径或依赖内部 API 的旧补丁。

本包不捆绑模型或提供一条自动安装全部 ML 依赖的命令。官方入口：[Demucs](https://github.com/facebookresearch/demucs)、[Whisper](https://github.com/openai/whisper)、[Torchaudio](https://github.com/pytorch/audio)。这些工具可选；已校准的 SRT/时间轴可直接使用。

## 最小时间轴

每句至少保存 text/start/end，词级时码可选。记录生成方式及 `listening_verified`，重复句必须各有实际出现的时段。对 end<=start、越界、重叠和空文本报错。停顿与间奏可用没有歌词的场景覆盖。

`plan.json` 是镜头/短语合同，不是自动转录文件。先纠正时序，再把短语映射为镜头或连续场景事件。关键短语的 scene_action 不等同于算法推断结果。

## 最终音轨

渲染器将用户指定的本地音频按原速度合入视频，不自动裁掉前奏或修改歌曲。默认要求音频与配置时长相符（容差 0.1 秒）；片段导出必须显式 --duration。音轨在 MP4 中会转成 AAC，不是位相同的原始文件。

比较源与成片的解码长度、起始偏移以及分段波形，随后实际播放核对唱词与画面。仅波形相似或零整体偏移不能证明字幕逐字同步。未试听时保持该项未核验。
